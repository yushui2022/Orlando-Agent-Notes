# 从 0 到 1 学 MQ：从消息传递到可靠的 Agent 任务

你已经会写接口、调用模型，也知道数据库能保存状态。接下来遇到的是：生成报告要两分钟，用户刷新页面后任务去哪了？Worker 崩溃后由谁接手？明明只提交一次，为什么外部工具执行了两次？

这套内容围绕一个贯穿案例：**用户提交资料，Agent 在受控环境里生成报告，平台保存结果并通知用户**。读完后，应当能为这条链路画出状态和失败路径，知道哪些保证属于 MQ，哪些必须由业务实现。
